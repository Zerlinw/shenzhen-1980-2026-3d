# 深圳 1980—2026 · 城市生长 3D 时间轴

从蛇口滩涂到深圳湾 APEC 的「左 → 右」三维时间轴纪录片原型。

**交付物：`index.html`（约 0.72 MB，单文件、零依赖、可离线双击打开）。**

## 打开方式

1. 直接双击 `index.html`（`file://` 已实测可运行，控制台无报错）。
2. 或用本地静态服务（推荐，便于分享）：

   ```bash
   cd shenzhen
   python -m http.server 8123
   ```

   打开 <http://127.0.0.1:8123/index.html>。

## 自动预演

打开后自动播放，约 **29.6 秒**走完 1980 → 2026；在 12 个关键年份各停顿 0.5–0.65 秒，结尾停在 2026 APEC 画面。

## 实现说明

- **Three.js r160.1**：内联进单文件。运行环境无外网（CDN 不可达），因此没有走 CDN，避免交付后打不开；渲染能力与 API 不变。
- **GSAP**：同样无法从 CDN 取得，改为自写的分段缓动时间轴（等效的 camera/year 缓动与关键年份停顿）。
- **OrbitControls / EffectComposer / UnrealBloomPass** 未引 addon：自写轨道控制、自写 Bloom（亮度阈值 + 三级高斯模糊）、ACES、暗角与胶片颗粒。
- **建筑生长**：`InstancedMesh` + 顶点着色器，按 `aYear` 从地面生长，`aEnd` 拆除；屋顶构件用 `aBaseY` 随主体一起升起，避免悬空。
- **全部程序化**：没有外部模型、贴图、字体、音频文件；标语牌与 APEC 光字由 Canvas 生成。
- 低多边形 + 手工调色，按年代插值天空、雾、光照、窗光比例。

## 目录

```

.src/                   拆分源码：app.js / style.css / shell.html
tools/build.mjs         把 three.min.js + 源码拼成 index.html
tools/shoot.mjs         无头 Chrome 截取关键年份（验收用）
tools/smoke.mjs         交互冒烟测试（播放/暂停/声音/年份/响应式）
.build/three.min.js     内联用的 Three.js 源

```

重新生成 `index.html`：

```bash
node tools/build.mjs
```
